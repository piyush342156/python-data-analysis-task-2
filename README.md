# Python Development Internship - Task 2

## Data Analysis with Pandas

This project is part of a Python Development Internship and focuses on basic data analysis and data wrangling using Python.

### Objectives

- Load and explore a dataset using Pandas.
- Identify and handle missing values.
- Clean and filter the data.
- Calculate averages and statistical summaries.
- Analyze correlations between numerical variables.
- Group and compare data by department.
- Create visualizations using Matplotlib and Seaborn.
- Extract meaningful insights from the dataset.

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Files

- `employee_data.csv` – Dataset used for the analysis.
- `Theskybrisk.ipynb` – Jupyter Notebook containing the complete analysis and visualizations.

### Key Analysis

The project analyzes employee information such as department, age, salary, years of experience, performance score, and satisfaction score.

The analysis includes data cleaning, descriptive statistics, department-wise salary analysis, salary distribution, experience versus salary relationships, and correlation analysis.
